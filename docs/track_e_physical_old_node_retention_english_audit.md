forbidden family. Let X⊆Y be actual Kpt seed sets; let R be
a **genuine** AlgorithmRun on X with top h, and Q a genuine
AlgorithmRun on Y with top H≥h. There is an ACTUAL seed

same levels or that Q has no novel auxiliary microcuts.

For every literal source-coordinate cut c<h, write

  ZR(c) = closure_(R.I(c+1))(X),
  ZQ(c) = closure_(Q.I(c+1))(Y).

The checked genuine cross-height selected-level theorem gives

  R.I(c+1) ⊆ Q.I(c+1).

Closure is monotone simultaneously in selected parameter levels
and seed sets, so

  **ZR(c) ⊆ ZQ(c)**.

This is an unconditional one-way *physical* Kpt node-set
retention theorem under the stated genuine-run hypotheses.
It is NOT equality: a new root can create additional actual
dependent parameters, I1/I2 forks or complete L+ crossings.
