# The constructed chronological graph as an actual one-gap G+ source

## English proof before implementation

The fair chronological construction gives a symmetric, loop-free graph
on the naturals, with all finite cliques smaller than four. An ordered
four-clique would give a four-element finite clique by taking the image
of its injective enumeration. Thus the graph avoids the actual normalized
Henson forbidden family, including loops and both asymmetric patterns.

Apply the already verified one-gap padding construction to this actual
graph. The padded countable partial structure avoids the same family.
Its canonical finite-prefix map into G+ is therefore an actual induced
embedding, obtained from the proved countable partial-structure API.

For original `i`, choose the meaningful one-gap address of its actual
chronological coding position. The coding positions are strictly
increasing, the one-gap addresses are strictly increasing, and the G+
prefix codes have size one more than their addresses. Therefore the
composite is injective and strictly increasing in code size. Its ordinary
binary table is the original prescribed graph at every distinct pair.
All auxiliary atoms on these originals are exactly their strict order:
one-gap spacing gives the forward auxiliary edge precisely when the
coding position increases.

## Boundary

The result constructs the source partial structure and its concrete G+
embedding from the fair K4 construction. It does not identify the
compressed source of an envelope with a diary record, prove all local
selected-neutrality conditions for individual events, or prove an upper
or lower Ramsey bound. The chronological construction currently certifies
round order and coding-last positions; the finer event ordering remains
a separate application step. No JEMS characterization is used.
