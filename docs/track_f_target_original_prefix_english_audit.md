# Track F — exact target-prefix one-type from an ACTUAL later original

17 November 2026. English proof / hostile audit committed before Lean.

The new non-root prefix-colouring theorem chooses a colour from
the actual target adjacency columns of a genuine source coding
vertex x under an injective index map e. To use its colour as an
ACTUAL target Henson one-type rather than a bare bit-vector,
the finite-prefix type must be certified K_(ell-1)-free. This

## Physical graph statement

Let ell>=2. Let E be the ACTUAL target graph edge table satisfying
the normalized Henson forbidden-family avoidance predicate, which
already implies symmetry and K_ell-freeness of EVERY initial prefix.
Choose any target cutoff H and any real target original vertex y>=H.
Set U={a<H : E(a,y)=true}, the precise old target neighbour set.

**Claim 1:** the finite set U contains NO directed
K_(ell-1)-clique. Otherwise an attained forbidden old clique
C⊆U of size ell-1, together with y, forms an ACTUAL
K_ell in the prefix [0,y+1): each old a∈C has E(a,y)=true,
and symmetry gives E(y,a)=true. The old clique C is disjoint
from {y} because its indices are <H<=y. This contradicts
normalized forbidden-family avoidance.

Thus U is an admissible target finite one-type over [0,H).
The construction does not require a target left-density axiom:
y is already an ACTUAL target original.

**Claim 2:** this target one-type has exactly the old adjacency
columns of y below H, in BOTH orientations:
E(a,y)=E(y,a)=decide(a∈U) for a<H.
This is an immediate consequence of the definition of U and
verified normalized Henson symmetry.

## Application

If e is any injective original-index map and x is an actual
source coding vertex whose image y=e(x) satisfies y>=H,
then the target H-prefix of the image x is represented by
an honest K_(ell-1)-free target one-type of level H.
No assumption that e preserves enumeration order is needed.
If a finite family of source coding vertices has the same
two-column target H-prefix colour, all their images satisfy
the same target type (provided each image lies after H).
This is the missing consistency bridge from a finite colour
to the non-root sourceCodingFibre predicate.

**Not claimed:** the target type's singleton rank equals the
source type rank. The source clique-richness and target-rank
comparison remain to be proved separately. The construction
does not prove that every prescribed finite sorted history
occurs in every induced Henson subcopy.

## Adversarial checks

1. The target original y is actual and >=H. A bare arbitrary
bit-vector may be inconsistent with K_(ell-1)-freeness.
2. Full target Henson avoidance implies symmetry; without it
a clique C of incoming neighbours need not be fully adjacent
to y in the reverse direction.
3. Old/new index separation is essential for exact clique
cardinality |C∪{y}|=ell.
4. The test concerns a CLIQUE in U, not its cardinality;
an independent U may be much larger than ell-1.
5. The proof uses global forbidden-family semantics rather
than assuming an unverified target old-prefix age axiom.
6. Both actual directed adjacency columns are preserved;
the selected target-prefix colour may later be defined
as their ordered pair, avoiding hidden symmetry assumptions.
7. This is a target-original extraction theorem, not
a statement that every hypothetical prefix type is realized
by a prescribed target vertex.
8. It does not identify singleton ranks across arbitrary
induced embeddings, nor compare full multi-sort graph ages.
