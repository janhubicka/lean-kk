# Track B — finite base-graph support determines the numerical-H old L-socle
**14 November 2026. English proof and adversarial audit BEFORE Lean.**

## Goal

The previous Track B cross-occurrence corrected-(B3) criteria require a common old ordinary-L socle on physical numerical-H structures at a common source cut. One checked shortcut assumes the two structures are truncations of the exact SAME base graph E and generation parameter k, which is much stronger than old-prefix equality.

This note identifies a genuinely FINITE, GEOMETRIC set of original base-graph edge pairs that can influence the numerical-H old ordinary-L socle at cut c. Matching the underlying base graph on just those pairs is sufficient for a complete old-socle comparison, including ALL absent/present directed binary, unary and diagonal atoms. This reduces another source-alignment obstacle without asserting that a proposed macrodiary already supplies the matching.

## Definition — relevant real-base pairs

Let `hPosition k i q := 2*(k+1)*i+2*q` denote the actual numerical-H coordinate of generation q in base-original block i. Define
```
RelevantBasePair k c i j :↔
  ∃ q m, i<j ∧ q≤k ∧ m≤k
      ∧ (q<m ∨ (q=m ∧ m=k))
      ∧ hPosition k i q ≤ c
      ∧ hPosition k j m ≤ c.
```

A positive directed H L-atom between two OLD coordinates x,y≤c is generated by exactly such an admissible pair of real copies, in one of the TWO tuple orientations. Conversely, any irrelevant original base pair can be changed without affecting any old binary atom through c. The same directed base edge `E i j` or reverse `E j i` is copied when and only when the corresponding physical real pair is allowed and its bit is positive. Odd fake coordinates contribute no binary L atoms.

The relevant set is finite: a pair with `hPosition k j m ≤c` satisfies `2(k+1)j ≤c` and hence j≤c; the first index i<j also ≤c. No uniform bound depending on the diary is claimed—only finiteness for this literal c,k.

## Theorem A — equality of all old numerical-H directed binary L bits

Take `E,F : Nat→Nat→Bool`, one generation bound k and source coordinate cut c, and suppose for every relevant pair `i,j` the **two directed base atoms agree**:
```
RelevantBasePair k c i j →
  E i j = F i j ∧ E j i = F j i.
```
For every x,y≤c, the entire one-symbol directed H binary atoms are equal:
```
hNumericBinary (normalizedGraphModel E).binary k x y 0
  = hNumericBinary (normalizedGraphModel F).binary k x y 0.
```
Proof by the checked `hNumericBinary_true_iff` formula. If its Boolean value is true, choose the actual generator `i,j,q,m` and its orientation. Since x,y≤c, both generator coordinates are ≤c; thus the pair is Relevant. The assumed directed base-bit equality transports the TRUE atom in the appropriate orientation. Symmetrize E,F to obtain the reverse implication, including equality of every false bit. No assumption of physical Kpt source, E-auxiliary relation, or generated I2 event enters here.

## Theorem B — old ordinary-L socle for two DIFFERENT base graphs

Let `A=finiteNumericHL(normalizedGraphModel E) k N1`, `B=finiteNumericHL(normalizedGraphModel F) k N2`, with c<N1,N2, directed base-pair agreement as above and `∀i, E i i = F i i`. Then
```
SameInitialL A B c.
```
Prove each component:
1. carriers agree through c because both numerical truncations contain every coordinate x≤c;
2. all directed binary bits agree by Theorem A, for every x,y≤c, including both orientations and all absent atoms;
3. unary symbols are absent in the graph signature, so the two unary functions are identically empty;
4. at a real numerical-H coordinate the diagonal is copied from the corresponding base-original loop `E i i`/ `F i i`, which agree globally by assumption; fake coordinates have the neutral false singleton.

For actual Henson base graphs, both are irreflexive and `E i i=F i i=false` automatically, so the diagonal condition costs nothing.

## Theorem C — physical HensonCutOccurrence adapter

Let `P,Q : HensonCutOccurrence ell c hell` have potentially different base E, original pools, finite heights and full Kpt closures, but assume `P.k=Q.k`. Both satisfy c<N by their `hCut` fields and have irreflexive base graphs. ```

No equality `P.E=Q.E` is required: E and F can disagree arbitrarily on higher original blocks or base pairs whose allowed numerical H coordinates are above c.

## Adversarial checks (17)

1. The finite relevant-pair predicate includes the actual generation gate `q<m ∨ q=m=k`, not just any two base-original indices below c.
2. BOTH directed base edge values must agree; in the abstract numerical model symmetry is not automatic, even though a real Henson graph satisfies symmetry.
3. All NEGATIVE directed binary L atoms are preserved by the true-bit equivalence, not merely the edge-support set.
4. The same generation parameter k is essential: changing k changes hPosition and its admissible pair gate. We make no k-transport assertion.
5. The source-coordinate c is literal and shared; different target numerical gap ranks require an independent reindexing.
6. The finite carrier truncations both contain c. If N1≤c<N2, carrier agreement fails even if all base edges agree.
7. A positive old H binary edge arises from REAL allowed copies; odd fake coordinates never contribute a binary atom, even if auxiliary E has a positive fake coordinate.
8. The diagonal channel is distinct from ordinary directed binary-on-distinct coordinates and must be handled, not silently omitted; equality of base LOOP bits suffices.
9. Unary symbols are absent for the normalized graph signature (du=0), but do not assert this for arbitrary finite relational languages without new assumptions.
10. Old source L-socle equality does NOT imply equality of auxiliary Kpt E columns, physical meet structure, or selected-level run decisions.
11. The old base-pair support is finite in c, but nothing here gives a DIARY-uniform finite bound on the number of relevant base originals.
12. Two base E can differ on relevant base edges above c while sharing old socle. The theorem deliberately permits those.
13. The next-cut full ordinary-L spectrum is an independent condition; old-base prefix matching alone does NOT transfer corrected B3.
14. The physical full-source exhaustiveness certificates are indispensable in Theorem D; one-sided `hRepresented` cannot be substituted.
15. The actual K4 q2 auxiliary positive cut neighbour may be encoded at an upper coordinate and is NOT erased by matching OLD base-pair support.
16. No arbitrary future–future edges in a corrected-B3 age witness are assumed to equal physical base E or F.
17. Full structural I1/I2/auxiliary E event traces, relative-continuation B3-loss, common labelled inverse-source orbit, unbounded resolved diary and independently unavoidable exact big Ramsey degrees remain OPEN.
