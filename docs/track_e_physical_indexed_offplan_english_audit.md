* Every live new index at level c has SOME live old index at level c.
  The old and new actual terminal nodes need not be identical.

new index cardinalities may differ. Both finite masks cover the
complete actual Kpt closure (meets and dependent parameters), not
selected-front graph ages.

any NEW I1 terminal has an OLD terminal; the second implies inclusion

`RunOld.I i ⊆ RunNew.I i`

`{q∈RunNew.I i : q≤oldTop} ⊆ RunOld.I i ∪ {q∈Allowed : i≤q}`

This constructs a *finite physical certificate interface* for the

In particular, old ordinary Henson-column agreement is insufficient
