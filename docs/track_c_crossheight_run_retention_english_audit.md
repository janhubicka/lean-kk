## A new issue: different top heights

The same-height monotonicity theorem has a direct downward induction because both AlgorithmRuns start with `I(top)={top}`. If the old and new runs have distinct scan tops t≤T, the new run's `I_new(t)` need not contain t merely from its top initialization at T. We need a **genuine old seed of level t**, not just an abstract top parameter.

For an actual old run associated with a finite Kpt envelope of nonempty originals, this is the natural top-height certificate. It is NOT automatic for arbitrary AlgorithmRun seeds (the run structure can be constructed for any chosen top).

## CH1 — abstract cross-height monotonicity of genuine selected levels

Let H be one fixed SMTree with actual meet/parameter closure, X⊆Y true node seed sets, and R, Q two actual AlgorithmRuns:

`R : AlgorithmRun H X t`,
`Q : AlgorithmRun H Y T`,
`t ≤ T`.

Assume **a physical old top seed** `∃x∈X,lev x=t`.

**Theorem:** for every i≤t,
`R.I(i)⊆Q.I(i)`.
In particular, `R.I0⊆Q.I0`: adding Kpt seeds AND increasing the scan top cannot delete an old selected level.

### Base i=t

R.topI={t}. We must prove t∈Q.I(t):

- If t=T, Q.topI={T}, immediate.
- If t<T, choose old top seed x∈X with lev x=t. Since X⊆Y and seeds lie in every genuine pre-cut closure, x belongs to
`closure (Q.I(t+1)) Y`. This is an actual (I1) witness at t for Q; `Q.interesting_step t` forces t∈Q.I t. This argument explicitly **uses** the old top seed and would be invalid without it.

### Downward step i<t

Assume `R.I(i+1)⊆Q.I(i+1)`. The independently checked seed/selected-level closure monotonicity from PR #194 gives
`closure_{R.I(i+1)} X ⊆ closure_{Q.I(i+1)} Y`.
The exact IsInterestingAt monotonicity (I1/I2 witnesses persist; I3 one-level-map impossibility persists under extra requirements) now applies.

- If R selects i (its actual pre-cut closure interesting), Q's closure is interesting too. Both `interesting_step` equations insert i, and the induction subset gives `R.I i⊆Q.I i`.
- If R skips i, `R.noninteresting_step` gives `R.I i=R.I(i+1)`. The larger Q may select i or skip it, but always `Q.I(i+1)⊆Q.I i` from its actual `level_step`. Chain the two inclusions.

Thus induction reaches i=0. No scalar B3 failure monotonicity or graph selected-shadow projection is postulated.

**Nonclaim:** this does NOT give equality of the two selected-level sets; the new root may create new I1/I2/I3 events. The genuine K4 auxiliary microcuts still matter.

10. At skipped R levels, use `Q.level_step` to show `Q.I(i+1)⊆Q.I i` even when Q selects.
