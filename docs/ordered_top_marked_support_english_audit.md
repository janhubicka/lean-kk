# Track A — exact ordered reserved-copy to entire selected top-front columns

**13 November 2026. English proof and adversarial audit before Lean.**

## Scope and inputs

Let `q : Nat→Nat` label a finite block of reserved originals
`q(0)<⋯<q(r−1)`; the indices need **not** be consecutive.
Fix height k, a pivot copy (a,g), with a<r, g≤k, the actual
finite numerical-H ordinary graph-L binary relation generated by
an original symmetric Boolean graph E, a finite set S of genuinely
future selected original indices, and a sort assignment
`tau : Nat→Fin d` **on the numerical top coordinates**.
The chosen support is `T⊆Fin d`.

Require all selected originals to be after *every* reserved original:
`∀ b<r, ∀ j∈S, q(b)<j`. Require the complete original uniform
support column simultaneously for ALL b and j:

```text
E(q(b),j) = decide(tau(iota_k(j,k)) ∈ T).
```

The hypothesis quantifies over every marked future original, not just
one special target. Distinct top coordinates may have the same
sort, so future-type multiplicity is not assumed injective.

Set `Q=orderedReservedNumericPrefix k q a g` (the genuine real
copies of the reserved block through the pivot),
`W=numericHTopPool k S`, and `U = W.filter(tau(_)∈T)`.

**Conclusion:** `Q` and `W` are disjoint, and for ALL u∈Q, w∈W,
both ordinary graph-L directions satisfy
`L(u,w)=L(w,u)=decide(tau(w)∈T)=decide(w∈U)`.

This produces the concrete entire-top-front **support hypothesis**
used by `finiteNumericH_ordered_marked_front_prefix_age_iff`.
It does not independently ensure old/reserve or gap/future
isolation, full chronological prefix coverage, age-reference
agreement, or actual existence of these simultaneous original
columns in Track B's schedule.

## English proof

Take u∈Q, w∈W. There are b≤a, t≤k, j∈S with
u=iota_k(q(b),t), w=iota_k(j,k). From a<r and b≤a,
q(b)<j by the exact all-front later-index hypothesis.
The verified `numericH_older_generation_to_top_exact`
therefore gives

```text
L(iota_k(q(b),t),iota_k(j,k)) = E(q(b),j).
```

The right-hand side is exactly the bit of T prescribed by
the uniform original column for the sort of top position w.
The verified symmetry theorem
`henson_finiteNumericH_binary_symmetric` proves the reverse
numeric arc. Both orientations are thus established, including
the **absent** bits for every sort outside T.

For disjointness of Q and W, a common coordinate would give
iota_k(q(b),t)=iota_k(j,k), t≤k. By the bounded-generation
injection theorem this forces q(b)=j, contradicting q(b)<j.
No assumption of consecutiveness, prescribed distance between
original indices, or injectivity of sort labels is required.

## Consequent exact graph-L age interface

Apply the ordered reserved-prefix capacity and complete
marked-front finite gluing lemmas with this actual top pool W.
They give, under the STILL EXPLICIT remaining old/reserve,
gap/future, safe-past and reference-table clauses:

```text
K_ell-free( P ∪ Q ∪ G ∪ W )
iff
```

This is a conditional, fully labelled **per-pattern** statement.
It is not an assertion that any separately abstract age-feasible

but does not give the actual resolved B/C/E source orbit.

For literal finite-H carrier membership, also require
`iota_k(q(a),g)<M` (reserved prefix) and

The Boolean binary formula itself does not check these bounds,
so a full physical application must supply them.

## Hostile checks

1. **One-target failure:** the K3 P4 `p-y-q-x` has q–x=1
   but also q–y=1 outside T={x}. The all-j hypothesis fails.
   Thus the theorem cannot hide the false marked-front inference.
2. **Top requirement:** the exact generation gate to selected
   top originals is always open for an earlier real copy;
   it is not the ordinary same-generation rule for arbitrary
   later generations. Replacing `iota(j,k)` by a lower
   generation invalidates the formula.
3. **Chronological requirement:** q(b)<j is essential.
   Without it, the gate can reverse orientation and suppress
   a positive original edge at some generations.
4. **Both directions:** original symmetry is an actual
   hypothesis; the directed clique test is not one-sided.
5. **No model relabelling:** all vertices use the unchanged
   original E at q(b),j and the unchanged hPosition map.
6. **Two different sorts may share the same adjacency column:**
   tau need not be injective. Separate selected originals can
   have equal types, and this changes neither edge proof
   nor capacity.
7. **Gaps are independent:** gaps between q-values and between
   q(r−1) and selected j are *not* part of Q. Their L columns
   must be checked in G separately; the theorem creates no
   zero bits for them.
8. **Reference age remains independent:** the E table on one
   fixed list of future originals does not represent every
   freely chosen internal future W graph automatically. The
   later age application is conditional on a full reference
   old-continuation table.
